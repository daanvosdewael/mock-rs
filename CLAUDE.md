# mock-rs

Rust crate implementing a text-mocking algorithm: alternating case with vowel-position weighting, special character correction, and optional phonetic garbling ("garble" mode). Builds a native CLI binary.

## Project Structure

```
mock-rs/
  Cargo.toml                          # single crate (lib + bin)
  src/
    lib.rs                            # pub fn build_mocking_text(input, garble) -> String
    main.rs                           # CLI entry point
    specials.rs                       # the e/i/l/o set: predicate + weight table
    alternate.rs                      # alternating case (weighted by specials)
    correct.rs                        # post-correction of e/i/l/o neighbors
    garble.rs                         # garble dictionary + phonetic replacement
  tests/
    parity.rs                         # integration tests against TS reference
```

## Commands

```sh
cargo build                                       # build
cargo test                                        # run all tests
cargo clippy                                      # lint (must pass without warnings)
cargo fmt                                         # format (default rustfmt)
cargo run -- "input text"                         # CLI normal mode
cargo run -- --garble "input text"                # CLI garble mode
```

## Architecture Decisions

- **Single crate with lib + bin** — `src/lib.rs` contains all transformation logic, `src/main.rs` is a thin CLI wrapper
- **Three verb-parallel stages** — `garble → alternate → correct`. Each stage is one file with a `*_word` function; `lib.rs` orchestrates the pipeline per word
- **`src/specials.rs` owns the e/i/l/o set** — both `alternate` (for the case-policy decision) and `correct` (for the per-position rewrite) consume `specials::is_special` and `specials::special_weight`
- **"garble"** — the phonetic dictionary (58 entries) is included; bitfactory, vegasquad, and corruption are excluded. The term "basmode" must never appear in the codebase

## Naming Conventions

- Rust standard: `snake_case` functions/variables, `PascalCase` types, `SCREAMING_SNAKE` constants
- Public API: `build_mocking_text(input: &str, garble: bool) -> String`
- Per-stage functions: `garble_word`, `alternate_word`, `correct_word`
- The e/i/l/o domain set lives in `crate::specials`: `is_special(c) -> bool` and `special_weight(c) -> i32`
- The option is called **`garble`** everywhere — the term "basmode" must not appear anywhere in code, comments, or commit messages

## TypeScript Reference Runner

A standalone runner at `../mock/utils/runner.ts` generates expected output for parity testing. It uses **only the garble dictionary** (bitfactory, vegasquad, corruption are excluded) and sorts regex keys by descending length for correct greedy matching.

```sh
npx tsx utils/runner.ts "foobar"              # normal mode  → FooBaR
npx tsx utils/runner.ts "foo bar"             # normal mode  → Foo bAr
npx tsx utils/runner.ts --garble "foobar"     # garble mode  → FooHwBaR
```

Run from the `../mock/` directory. Requires `tsx` (available via npx in that project).

## Test Corpus

`test-corpus.json` contains all expected input/output pairs generated by the TypeScript reference runner. It has two top-level keys:

- **`normal`** — 93 cases with `garble=false`
- **`garble`** — 97 cases with `garble=true`

Each entry is `{ "input": "...", "expected": "..." }`. Covers single chars, special char combos (e/i/l/o), case variations, numbers, punctuation, symbols, whitespace edge cases (leading/trailing/multiple spaces, tabs), unicode (accented chars, emoji, CJK), all 44 garble dictionary keys in isolation, Dutch words with overlapping garble patterns, and multi-word sentences.

## Testing

- Unit tests in each module: `#[cfg(test)] mod tests { ... }`
- Parity tests (against TypeScript reference) in integration tests (`tests/parity.rs`)
- Generate expected values with the TS runner, then assert in Rust
- Always test both normal and garble modes
- Canonical assertions: `build_mocking_text("foobar", false)` = `"FooBaR"`, `build_mocking_text("foo bar", false)` = `"Foo bAr"`
